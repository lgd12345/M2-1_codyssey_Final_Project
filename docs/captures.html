MORRONO / ACTUAL SERVICE WALKTHROUGH

현재 발표 관련 시연 캡처 29장.

시연 문의 CLM-146 · VMCT-02. 접수·분석·원본 열람·대화·AI 메일 작성·고객 이력 화면. 발표 사용 이미지 6장. 구현 변경 이전의 실제 촬영 기록이며, 폐기 기능과 관련된 18장은 현재 발표·갤러리에서 제외하고 원본·촬영 기록만 보존.

가상 고장 접수이며 실제 설비 점검·수리나 부서 메일 발송은 하지 않음. 메일 주소와 다른 문의 목록은 가림 처리. 실제 사용자 5명 이상의 피드백 수집을 대체하는 자료가 아님. 40번은 같은 입력 내용의 양식을 재촬영했으며 추가 접수 없음.
